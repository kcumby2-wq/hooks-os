# Release Room Friday — Weekly Athlete-Story Content Series

> **⬢ Operating altitude:** `P` · content pillar · single-production-cycle multi-platform distribution
> **⬢ Trusted-agent spec (7Q):** shadow-pending
> **⬢ Operational lead:** Margin (athlete selection + narrative approval) · Will/production team (shoot + edit) · Kyron (distribution) · runs weekly

**Purpose:** Turn Margin's alumni network into a recurring content engine — not a static testimonial page. One short-form video per week, built to the same four-beat structure, distributed across every platform from one production cycle.

**Return per Growth Plan:** *"A content engine built from wins Margin already has — no new material to create from scratch every week."*

---

## The four-beat structure · every episode, same shape

Every Release Room Friday episode delivers:

1. **One athlete story** — who is this receiver, what level is he at, what's his origin with Coach Hooks
2. **One specific drill or technique breakdown** — the actual work · shown on tape · not abstract
3. **One measurable result** — 40-time drop, contested-catch rate, offer received, All-American selection · numbers, not vibes
4. **One takeaway every young receiver can apply** — the technical extract · what a 12-year-old watching this can go do tomorrow

**Length:** 60-90 seconds short-form video. Optional 3-5 minute long-form on YouTube for the same episode.

## Athlete selection · rotating spotlight

**Rotates across:**
- Alumni (NFL / CFL / College current roster) — highest gravity content
- HS All-Americans (recent + current-year)
- Cohort standouts (fresh · under-the-radar · builds STL cohort demand)
- Youth breakthroughs (rarer · high-authenticity)

**Segment weighting per quarter:**
- 60% Alumni + College (highest reach)
- 25% HS All-American
- 10% Cohort standout
- 5% Youth

**Consent required.** Every athlete featured signs a media-usage consent (via `athlete-brand-pipeline/` handshake).

---

## Voice register

Every episode runs through:
- **`margin-voice/`** — direct · technical · honest-before-encouraging · no hype vocab
- **`outcomes-based-communication/`** — the "measurable result" beat is outcome-language, not feature-language

**Anti-pattern voice examples:**
- "Marvin's crushing it in the NFL!" (hype · vague)
- "Amazing work from our star athlete!" (marketing · flat)

**Right voice examples:**
- "Third-year returner. Two All-Pro nods. Same release we drilled at 15."
- "Cut his 40 by two-tenths in eight weeks. This is the drill we ran."

## Production cadence

**Weekly rhythm:**
- **Monday:** Margin flags the featured athlete + one drill/moment
- **Tuesday-Wednesday:** shoot or pull existing footage · script the four beats
- **Thursday:** edit + write captions per platform
- **Friday:** publish across all platforms in one distribution block
- **Weekend:** monitor engagement · queue best-performing clip for boosted retargeting

**When Margin's on the road:**
- Pre-shot library exists to pull from
- Never break the Friday cadence · consistency compounds

---

## Anti-patterns

- Different episode structure each week (audience never learns to expect it)
- Platform-native content built separately for each channel (5x the work · 1x the ROI)
- Testimonial-only ("player X loved the training") — every episode needs the technical beat
- Featuring an athlete without consent (breaks trust · legal risk)
- Skipping a week (the compounding is in the consistency)
- Metaphor-heavy captions ("he was BUILT different" · "GRIT SEASON is HERE") — voice discipline per `margin-voice/`
