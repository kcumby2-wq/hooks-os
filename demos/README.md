## Live artifacts

### `margin-hooks-demo-prompt.md` · v1.0 · 2026-07-20

**Audience:** Margin Hooks (trainer · flagship Tier 3 customer)
**Occasion:** Pre-Season Walkthrough Zoom · first week of August 2026 (per hooks-os Goal P2)
**Format:** Fable-prompt · pasted into Claude Fable 5 · outputs single-file interactive HTML
**Target emotional response:** relief · then power · then legacy. Sundays back. Voice preserved. 20 years compounding into Personal LLM IP.
**Owner:** Kyron Cumby

**How to use:**
1. Open a fresh Claude Fable 5 session at claude.ai (model = `claude-fable-5`)
2. Paste the entire prompt from `# YOUR MISSION` through `**Now build.**` in `margin-hooks-demo-prompt.md`
3. Fable outputs an HTML Artifact
4. Test in Chrome on the presenting laptop
5. Iterate against Chills Checkpoints (Appendix B) — if a checkpoint doesn't hit, ask Fable to fix that specific act
6. Rehearse the presenter voiceover (Appendix C) against the demo before the Zoom
7. Save the final HTML file · deliver during the walkthrough

**When to iterate the prompt itself:**
- If Fable's output feels like a CRM or a fitness app: the anti-patterns section needs sharpening
- If Margin doesn't feel Sunday-night named on Act 1: rewrite the Sunday-night text block
- If the Personal LLM path doesn't land: the Year 2 tentpole line needs more weight
